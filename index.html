Chapter one · Where it starts

A curious kid in India

Growing up in India, school was where the questions started — and where a computer first felt less like a machine and more like a place to build things.

My first language was Java. Loops and logic, the small thrill of making something run. I didn't know the word "engineer" yet. I just knew I wanted to make the thing work.

Chapter two · The first real thing

Teaching a machine to find justice

Computer Engineering · University of Mumbai

In college I built an ML model to help identify relevant judicial cases — surfacing the most recent, most relevant precedent from a pile of legal text instead of leaving someone to search by hand.

It was the first time I saw the shape of what I'd keep doing: putting AI in front of a real problem for people who don't have time to be technical about it.

Building the plumbing

Data Engineer · Accenture, Mumbai · 2018–2021

This is where I learned that the unglamorous part — the data being right — is the whole job.

Chapter six · Where it landed

AI for a city

Data Analyst · City of Rochester, New York · 2023–2026

I built AI and data systems inside government — a four-node agent on AWS Bedrock, retrieval that kept policy answers grounded in real documents, and the judgment to escalate to a human when the machine shouldn't decide alone.

Scoped with non-technical staff, built for records retention and auditability from day one. The kid who wanted to make the thing work got to make it work for a whole city.

I also took it to the stage — a featured speaker at Flower City AI, talking about the technical and the policy sides of deploying AI people can trust.

And on the side — the founder instinct, shipping

Things I build when nobody assigns them

FinRAG

Nobody wants a chatbot that guesses at their bank balance.

Reads credit card statements and answers spending questions in plain English. Arithmetic routes to SQL because it has to be exact; pattern questions go to vector search. The model formats the answer, it never calculates it — and everything runs locally, no external API.

FastAPI · PostgreSQL · pgvector · Ollama · sentence-transformers

Code and decision log

PR Review Agent

Four opinions on one diff are worse than one, unless something reconciles them.

A multi-agent code reviewer: an orchestrator routes chunks to specialists for security, performance and style, then a critic reconciles, de-duplicates and assigns severity before anything posts. Traced with LangSmith, evaluated with DeepEval.

LangGraph · LangChain · Groq · LangSmith · DeepEval

Code

Voice receptionist

A flooded basement should never reach an AI.

A voice agent for a plumbing business, designed from the calls the owner actually gets. Emergencies route straight to a person; the assistant books the routine work. A webhook turns call audio into structured booking records.

Retell · Cloudflare Workers · Airtable

Portfolio agent

Retrieval, summarising and delivery should fail separately.

Claude connected to a custom MCP server exposing brokerage data as callable tools, delivering plain-English portfolio digests over Telegram. Scheduled jobs stay independent, so a delivery hiccup never takes the summary down with it.

Claude · MCP · APScheduler · Telegram Bot API
