Selected work

FinRAG

Nobody wants a chatbot that guesses at their bank balance.

A local system that reads credit card statements and answers questions about spending in plain English. Every question is routed before retrieval: arithmetic goes to SQL because it has to be exact, pattern questions go to vector search. The model formats the answer, it never calculates it.

Statements are sensitive enough that everything runs on the machine, with no external API. Measured across seven question types, embedding the merchant and category reached 80% accuracy, while adding the raw description dropped it to 73% because store numbers and transaction codes came along with the useful terms.

FastAPI · PostgreSQL · pgvector · Ollama · sentence-transformers

PR Review Agent

Four opinions on the same diff are worse than one, unless something reconciles them.

A multi-agent code review system. An orchestrator routes chunks of a pull request to specialist agents for security, performance and style, then a critic agent reconciles what they found, strips duplicates and assigns severity before anything is posted. A human still approves the merge.

Traced with LangSmith and evaluated with DeepEval, so a change to a prompt has a measured effect rather than an assumed one.

LangGraph · LangChain · Groq · LangSmith · DeepEval · GitHub Actions

Voice receptionist

A flooded basement should never reach an AI.

A small business misses calls while its people are under a sink, and every missed call goes to whoever picks up next. The design started from the calls the owner actually gets: burst pipe, no water, water through the ceiling. Emergencies route straight to a person. The assistant books the routine work, which is most of the volume and the part where a mistake costs an appointment slot rather than someone's house.

A webhook turns unstructured call audio into structured booking records, so nothing has to be typed up afterwards.

Retell · Cloudflare Workers · Airtable

Portfolio notification agent

Retrieval, summarising and delivery should be able to fail separately.

Claude connected to a custom MCP server that exposes brokerage account data as callable tools, delivering plain English portfolio digests over Telegram. Scheduled jobs are kept independent, so a formatting failure in delivery does not take the summary down with it.
